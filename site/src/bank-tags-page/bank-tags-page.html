Bank Tags

View and edit layouts synchronized by Bank Tags Extended. Explore layouts. Inventory Setups.

Loading bank tags…

    Select a synchronized bank tag.

    Add an item

    Type at least 2 characters. Use ↑/↓ to browse and Enter to select.

    Bank tag editor controls

    ?
    Open this help.
    Esc
    Close this help.
    Ctrl/⌘ + S
    Save the selected tag.
    Item explorer
    Select Add item, or click an empty layout slot. Search by partial name or item ID, then use ↑/↓ and Enter.
    Drag and drop
    Move an item to an empty slot, or swap two layout items.
    Double-click
    Empty a layout slot without removing the item from the tag.
    Red ×
    Remove the item from the tag entirely. This also clears every layout slot containing it.
    Revision history
    Preview or restore prior saved versions. A restore creates a new revision and preserves the current one.
    New layout tab
    Create an empty synchronized tag after reviewing a confirmation message.
    Folders
    Create one-level folders, select a folder to assign and order tags, and use the arrow control to collapse it locally.
    Delete layout tab
    Delete the synchronized tag only after typing its exact name.
    Dissolve folder
    Delete the folder after typing its exact name. Its tags remain synchronized and become unfiled.

    Imports are drafts until you select Save changes. RuneLite receives saved changes during its next synchronization.
